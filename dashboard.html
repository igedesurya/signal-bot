    Grafik harga + sinyal B / J

    Segitiga hijau B = mulai menarik untuk beli, merah J = mulai bahaya.





    Candle hijau = harga naik   Candle merah = harga turun   Garis biru = garis cepat (SMA20 / TEMA9)   Garis oranye = garis acuan (SMA50 / BB tengah 20)
    Segitiga B = di candle itu muncul tanda mulai menarik untuk beli  |  Segitiga J = di candle itu muncul tanda mulai bahaya, waktunya hati-hati/kurangi
    Arahkan kursor ke chart untuk lihat detail tiap candle.
